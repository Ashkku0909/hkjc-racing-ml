# Contributing to HKJC Racing ML Pipeline

Thanks for your interest in contributing! 🎉

## ⚠️ Important: Educational Purpose

This project is **strictly for educational and research purposes**. Contributions should align with:
- Data science / ML education
- Statistical analysis techniques
- Software engineering best practices
- NOT actual gambling or betting promotion

## How to Contribute

### 🐛 Reporting Bugs
Open an issue with:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Your environment (OS, Python version)

### 💡 Suggesting Features
Open an issue tagged `enhancement` describing:
- What problem the feature solves
- How it fits the educational purpose
- Any implementation ideas

### 🔧 Pull Requests

1. **Fork** the repo
2. **Create a branch**: `git checkout -b feature/my-feature`
3. **Make changes**: Keep code clean and documented
4. **Test**: Make sure nothing breaks
5. **Commit**: Clear, descriptive commit messages
6. **Push**: `git push origin feature/my-feature`
7. **Open PR**: Describe what you changed and why

### 📋 PR Guidelines
- Keep PRs focused — one feature/fix per PR
- Follow existing code style
- Add comments for complex logic
- Update README if adding new features
- Ensure no API keys or secrets are committed

## Code of Conduct

Be respectful, constructive, and remember this is an educational project. We're all here to learn.

## Questions?

Open a discussion or issue — happy to help!
